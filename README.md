# Cyverdarian CLI

A lightweight command-line toolkit designed to assist during Capture The Flag (CTF) competitions.

## Purpose

Cyverdarian CLI provides quick access to categorized CTF references and workflows, helping users work more efficiently during challenges.

Current categories include:

- Cryptography (Ciphers, encoding, decoding, and hashing)
- Diffie-Hellman & XOR (Custom Decryption Functions)
- Digital Forensics (File analysis, hidden data, and metadata)
- Steganography (Hidden data in images, audio, and extraction)
- Metadata Extraction & Decryption (Advanced Parsing)
- Network & Reconnaissance (Port scanning, SMB audits, and remote access)

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cyverdarian-cli.git
cd cyverdarian-cli
```

Run the installer:

```bash
chmod +x install.sh
./install.sh
```

Open a new terminal session after installation.

## Requirements

- Linux
- Bash
